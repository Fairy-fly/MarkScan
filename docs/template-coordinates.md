# MarkScan v1 模板坐标

规范图像 1240×1754，左上角为 (0,0)，x 向右，y 向下。A4 纵向、约 150 dpi。

| 元素 | 像素坐标 |
| --- | --- |
| 四角黑方块中心 | (80,80)、(1160,80)、(1160,1674)、(80,1674) |
| 黑方块大小 | 45×45 |
| 方向校验码 | y=210，x=420+70i，i=0..4，黑白模式 10110 |
| 第 q 题第 a 个选项中心 | (440+160a, 420+110q)，q=0..9，a=0..3 |
| 印刷圆圈 | 半径 25，边宽 2 |
| 填涂统计区域 | 半径 17 的圆盘，面积 901 像素 |
| 填涂判定 | 二值图圆盘黑色比例 ≥ 0.40 |
| 评分 | 恰好单选且与配置一致计 10 分，其余 0 分 |

定位采用轮廓面积、四边形近似、凸性、矩形占有率过滤候选方块。枚举凸四边形并按面积排序，最多验证 60 组、每组 4 个旋转方向。透视变换把定位方块中心映射到规范坐标。方向码与至少 36/40 个选项印刷圈通过检查后才继续识别；不会仅凭四个任意方块输出分数。

阈值图：灰度 → 3×3 高斯模糊 → 51×51 高斯自适应反向二值化，C=12。圆盘掩模通过 bitwise_and 与 countNonZero 计算比例。内圆与印刷圈留有 8 像素半径差，避免正常空圈边缘计入填涂。所有参数在 core/Recognizer.* 中可查。

模板与样例由 tools/SheetFactory.cpp 绘制。tests/core_tests.cpp 的期望答案与分数仅用于断言，不传入 recognize；换标准答案只改变评分、不改变图像识别结果。
