# 发布范围

仓库先创建为 Private，转 Public 由作者决定。

纳入源码、CMake、模板、标准答案、合成测试输入与测试源码、两张真实截图和审查后的验证记录。排除 build、SDK、Gradle 缓存、课程报告及生成脚本、提交包、备份、录屏、原始设备日志和旧二进制。本地原件保留，整理前文件备份于忽略的 backups/github-preparation。

当前不创建 v1.1.0 Release：旧 APK / Windows 包的“关于”包含个人信息；清理后的 Android APK 尚未重新真机验证，二进制依赖许可也需复核。后续从仓库提交重新构建、验证并审查后再发布，不混入课程材料。

公开前由作者选择项目许可证，当前不擅自添加授权条款。
